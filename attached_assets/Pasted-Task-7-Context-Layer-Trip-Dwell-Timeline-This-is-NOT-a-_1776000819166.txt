Task 7 — Context Layer (Trip + Dwell + Timeline)

This is NOT a feature expansion.

This is a clarity upgrade.

---

# 🎯 OBJECTIVE

Help the watcher instantly understand:

* Where is the person?
* Are they settled?
* Are they moving?
* Should I worry?

WITHOUT needing to read a lot

---

# 🧠 CORE PRINCIPLE

Context > Data

---

# 🔧 BUILD REQUIREMENTS

## 1. DWELL DETECTION

If user stays within ~50m for >5 minutes:

Create a "place" state:

Examples:

* "At Home for 2 hours"
* "At Work for 30 minutes"
* "At [Detected Location]"

---

## 2. SIMPLE PLACE LABELING

Start simple:

* Home
* Work
* Frequent location

Fallback:

* readable location name

NO coordinates shown

---

## 3. TRIP DETECTION

If movement >100m AND speed >15 km/h:

Trip starts:

Show:

* "Left Home 8 minutes ago"
* "On the way"

Trip ends:

* "Arrived at Work"

---

## 4. WATCHER VIEW (PRIMARY)

Show only:

* Safety status (existing)
* Context line (NEW)

Examples:

🟢 Safe
"At Home for 2 hours"

🟡 Quiet
"Quiet for 6 minutes — last seen near Office"

🔴 Concern
"We're checking on Sarah"

---

## 5. TIMELINE (SECONDARY VIEW)

Create collapsible section:

Examples:

* 10:15 — Left Home
* 10:45 — Arrived at Office
* 2:00 — Quiet for 5 minutes
* 2:05 — Back online

---

## 6. DO NOT BUILD

* route replay
* speed logs
* complex analytics
* detailed tracking history

---

## 7. PERFORMANCE RULE

* use clustering logic
* do NOT log every GPS point
* generate events only

---

## 8. UI CONSTRAINT (CRITICAL)

DO NOT increase text density.

If adding context:
→ simplify existing text

---

# 📦 OUTPUT REQUIRED

Report:

1. How dwell is detected
2. How trip start/end is detected
3. Example watcher UI before vs after
4. Timeline view behavior
5. Confirmation that UI did NOT become more cluttered

---

# ⚠️ DO NOT TOUCH

* heartbeat system
* safety state engine
* concern flow

---

Goal:
→ make StillHere feel effortless to understand
