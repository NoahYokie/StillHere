  Re: Privacy Nutrition Label Q1-Q6 Answers

  Good draft. Answers below.

  Q1. Email address

  Yes, declare Email Address as collected, but optional.

  StillHere does not collect the account holder’s email as a core login field, but the app can store emails for:

  contact emails
  watcher report preferences
  email alerts/reports

  So App Store label should say:

  Email Address:
  Collected
  Linked to user
  Not used for tracking
  Purpose: App Functionality

  Note:
  Optional. Used only if the user or contact flow provides an email.

  Q2. Voice call recordings

  Assumption: StillHere does not record calls.

  Before final label, please verify with a code/config audit:

  Twilio recordings are not enabled.
  No WebRTC audio is stored server-side.
  No audio blobs are written to DB or object storage.
  No call recording webhook exists.

  If confirmed:
  Audio Data = Not collected.

  If any recording is enabled:
  Audio Data must be declared.

  Do the audit before finalizing.

  Q3. iOS Contacts permission

  Current direction:
  No OS Contacts permission.

  Users manually type Safety Circle contact details.

  So:
  Do not add NSContactsUsageDescription.
  Do not request address book access.

  For privacy label:
  Declare manually entered Safety Circle contact info under:

  Contact Info → Other User Contact Info

  Do not declare Apple “Contacts” unless the app reads the device address book.

  Please verify one final grep for Capacitor Contacts, navigator.contacts, CNContactStore, or iOS Contacts picker usage.

  Q4. Server logs / PII

  Before final label, run a one-time log/privacy grep audit.

  Look for raw:
  phone numbers
  lat/lng
  email addresses
  SMS bodies
  tokens
  authorization headers
  watcher links
  emergency links

  If found:
  redact or mask before App Store submission.

  If no raw PII is logged:
  Diagnostics answer can remain:
  Other Diagnostic Data, linked to user where applicable, App Functionality, not tracking.

  Also verify Replit stdout does not routinely print raw coordinates or phone numbers.

  Q5. Location retention

  Yes, draft the privacy policy retention sentence.

  Use:

  “StillHere stores location data only when location sharing or a safety feature is active. Location history is retained according
  to your location retention setting, with 30 days as the default. Location tied to an open safety incident may be kept while the
  incident is active. Deleting your account removes your StillHere location history from our active database.”

  If this is not technically true for every table, flag the mismatch before adding the sentence.
