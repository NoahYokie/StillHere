Task — Home Redesign + Side Navigation Cleanup

I want to redesign the StillHere home experience based on the new approved direction.

Goal:
Make the home page simple, calm, short, and premium.

The current home page feels too loaded. We need the home screen to focus only on the most important safety actions, and move secondary features into a clean side drawer.

---

# 🎯 OBJECTIVE

Create a clean “Focus Mode” home screen with:

1. protected status
2. big “I’m OK” button
3. next check-in
4. four quick actions:

   * Timer
   * Safe Walk
   * Drive
   * SOS

Everything else should move into the side menu or relevant secondary pages.

The app should feel:

* calm
* premium
* simple
* trustworthy
* not like a crowded dashboard

---

# PART 1 — HOME SCREEN REDESIGN

## Required layout

### Top bar

Keep a clean top bar:

Left:

* hamburger menu icon

Center:

* StillHere

Right:

* notification bell

Do not show many icons across the top anymore.

---

### Status section

At the top of the home content show:

Icon: shield/check

Text:

* “You’re Protected”
* “Sharing with 1 Guardian”

This should be clean and centered.

If dynamic data exists, use it:

* number of guardians
* current safety/sharing status

If no guardian:

* “Set up your Safety Circle”

---

### Main action

Large centered green circle button:

Text:

* “I’M OK”

Subtext underneath:

* “Tap anytime to let your guardian know you’re okay”

This is the visual focus of the screen.

The button should feel important but calm.

---

### Next check-in card

Show one clean card:

Text:

* “Next check-in”
* time, for example “10:10 PM”
* date/location timezone, for example “Today · Perth”

Keep this compact.

---

### Quick actions row

At the bottom of the main content show four equal quick actions:

1. Timer
2. Safe Walk
3. Drive
4. SOS

Use large rounded icon tiles.

Color direction:

* Timer = orange
* Safe Walk = green
* Drive = blue
* SOS = red

SOS should be visible but not visually overwhelming unless pressed.

# PART 5 — VISUAL STYLE

Use a clean mobile-first style:

* white / off-white background
* soft cards
* rounded corners
* subtle shadows
* lots of spacing
* no crowded icon rows
* no heavy gradients unless very subtle
* calm green as primary safety color
* red only for emergency actions

The design should feel closer to:

* Apple Health
* premium banking app
* calm safety companion

Not:

* technical dashboard
* admin panel
* overloaded web app

---

# PART 6 — RESPONSIVE BEHAVIOR

* iPhone-sized screen
* mobile browser
* PWA
* desktop browser narrow width

On desktop:

* keep the mobile app container centered
* do not stretch content too wide
