Task 8 — Notification Engine (Concern + Arrival)

We are now building the bridge between the app and real life.

Goal:
Ensure watchers do NOT need to open the app to feel informed and reassured.

---

# 🎯 CORE FEATURES

## 1. Concern Notifications (HIGH PRIORITY)

Trigger:

* safetyState → concern
* heartbeat silence (engine)
* SOS / crash detection

Message examples:

"Action Needed: Sarah hasn’t been reachable for 5 minutes."
"We’re trying to reach Sarah now."

Requirements:

* must be immediate
* must include name
* must include reason (human-readable)
* must NOT sound robotic

---

## 2. Recovery Notifications (CRITICAL)

Trigger:

* heartbeat resumes
* concern resolved (user or watcher)

Message examples:

"Sarah is back online — everything looks good."
"Connection restored — no further action needed."

This is mandatory — prevents false alarm anxiety.

---

## 3. Arrival Notifications (HIGH VALUE)

Trigger:

* trip_end → dwell_start
* resolved place name exists

Message examples:

"Sarah arrived at Home"
"David arrived at Work"
"Sarah arrived safely"

---

## 4. Notification Tone (VERY IMPORTANT)

Tone must feel:

* calm
* human
* reassuring

Avoid:

* robotic system wording
* alarmist language unless concern state

---

## 5. Deduplication (REQUIRED)

Prevent spam:

* if user oscillates at geofence edge → no repeated alerts
* implement 2-minute cooldown per place/event

---

## 6. Notification Preferences (BASIC CONTROL)

Watcher can toggle per person:

* arrival notifications ON/OFF
* concern notifications ALWAYS ON

---

## 7. Payload Requirements

Each notification must include:

* name
* event (arrival / concern / recovery)
* place (if available)
* timestamp (optional display)

---

# 📦 OUTPUT REQUIRED

2. Trigger conditions implemented
3. Deduplication logic explanation
4. Preference toggle implementation
5. Confirmation notifications work via:

   * push
   * SMS fallback (if already wired)
