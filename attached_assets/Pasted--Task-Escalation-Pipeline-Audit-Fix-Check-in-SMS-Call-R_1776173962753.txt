# 🧪 TEST SCENARIO (REAL ISSUE)

User A and User B are mutual emergency contacts.

Both intentionally miss check-ins.

Observed behavior:

1. User A:

   * Receives call ✅
   * Presses "1" to confirm safe ✅
   * ❌ User B receives NO notification (SMS, push, or in-app)

2. User B:

   * ❌ Does NOT receive escalation call at all
   * ❌ Does NOT receive SMS escalation

This indicates broken escalation + notification pipeline.
