Task — Safety Circle WOW Redesign

I want to redesign the Safety Circle page so it feels like a real protection system, not a settings/contact page.

Current problem:
The page works, but it feels too basic. It shows guardians and buttons, but it does not create a strong emotional feeling of:
- “these people are ready”
- “the system knows what to do”
- “I am protected”

Goal:
Turn Safety Circle into one of StillHere’s strongest trust-building screens.

---

# 🎯 OBJECTIVE

Build a premium Safety Circle experience with:

1. readiness hero
2. guardian cards
3. how-it-works escalation flow
4. upgraded safety drill
5. drill results
6. guardian view preview access

The page should feel:
- calm
- protective
- premium
- human
- simple
- not like a settings page

---

# PART 7 — GUARDIAN VIEW SCREEN / PREVIEW

Upgrade the “See my Guardian’s view” experience.

## Header:
- Guardian’s View

## Main text:
- This is what your guardian sees

## Show:
- map preview or status card depending on sharing mode
- current status
- last check-in
- next check-in
- battery if available
- sharing/privacy explanation

Examples:
- Your status: All good
- Last check-in: Today, 8:25 PM
- Next check-in: Today, 10:10 PM
- Battery: 78%

## Privacy note:
Use the correct wording based on sharing mode.

For precise:
- They can see your precise location while sharing is on.

For area:
- They can see your general area, not your exact location.

For presence:
- They can see your safety status, not your location.

For paused:
- They cannot see your location while sharing is paused.

Important:
This must reflect real current sharing mode and real API redaction behavior.

# PART 11 — VISUAL STYLE

Use the same design language as the new home screen:

- white / off-white background
- soft cards
- rounded corners
- subtle shadows
- calm green as primary
- blue for informational states
- amber for idle
- red only for true concern
- generous spacing
- mobile-first max-width container

Do not make it look like an admin dashboard.

It should feel like:
- Apple Health
- premium care app
- calm safety companion

---

# PART 12 — DATA + FALLBACK BEHAVIOR

Use real existing data wherever possible.

If data is unavailable:
- use initials instead of avatar
- show Ready only if supported by current watcher health
- otherwise use neutral status:
  - Guardian added
  - Status unavailable

Do not fake data that does not exist.

If last active is unavailable:
- hide it or show:
  - Readiness not checked yet
